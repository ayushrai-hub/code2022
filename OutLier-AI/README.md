# OutLier-AI - Python ML/AI Scripts

A collection of Python scripts and exercises for machine learning and AI, organized by learning weeks.

## Overview

This project contains Python scripts organized by weeks, with each week containing various tasks and exercises related to machine learning and artificial intelligence.

## Project Structure

```
OutLier-AI/
├── PythonScriptsOutlierWeeks/
│   ├── task1/              # Initial tasks
│   ├── week1/              # Week 1 exercises
│   ├── week2/              # Week 2 exercises
│   └── ...
├── .venv/                  # Python virtual environment (excluded from git)
├── myenv/                  # Alternative virtual environment
└── README.md               # This file
```

## Purpose

This appears to be a learning/exercise project for:
- Machine learning algorithms
- AI implementations
- Python programming practice
- Data processing and analysis

## Usage

### Setup

1. Navigate to the project directory:
```bash
cd OutLier-AI
```

2. Create a virtual environment (if not already created):
```bash
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate
```

3. Install dependencies (if requirements.txt exists):
```bash
pip install -r requirements.txt
```

### Running Scripts

Each script can be run independently:

```bash
python PythonScriptsOutlierWeeks/week1/task1/script.py
```

## File Naming Conventions

Scripts appear to follow this pattern:
- `response1.py`, `response2.py` - Different response attempts
- `ideal_completion.py` - The ideal/optimal solution
- `test_*.py` - Test files for validation

## Development Notes

- Each task may have multiple solution attempts
- Ideal completions serve as reference implementations
- Test files validate correctness
